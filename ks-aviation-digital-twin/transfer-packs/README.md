# KS Gemini Nathan 1+2 paket yükleme

GitHub **Add file → Upload files** ile bu klasöre altı ZIP dosyasını yükleyin. GitHub Actions, ZIP içeriklerini güvenli biçimde proje köküne açar, ZIP paketlerini siler ve `main` dalına işler. Eski depolar bu iş akışından etkilenmez.

Dosyalar: `01-kaynak-r14-zemin.zip`, `02-nathan-model-a.zip`, `03-nathan-model-b.zip`, `04-nathan-model-c.zip`, `05-public-earth.zip`, `06-public-diger.zip`.
